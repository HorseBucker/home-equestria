# Home: Equestria

A VR (and desktop) life-sim in Ponyville. Current version: **0.0.7-maredev** (install 0.0.4-maredev, then press Update on the title screen or pause menu).

### Which files do I need?

| You want to... | Download |
|---|---|
| Play on Windows | Windows from MEGA, **or** both `windows.zip` parts from the [0.0.4-maredev release](https://github.com/homedevanon/home-equestria/releases/tag/0.0.4-maredev), then update in game |
| Play on Linux | Linux from MEGA, **or** both `linux.tar.gz` parts from the [0.0.4-maredev release](https://github.com/homedevanon/home-equestria/releases/tag/0.0.4-maredev), then update in game |
| Play on Quest standalone | Quest from MEGA, **or** the `quest.apk` from the [0.0.4-maredev release](https://github.com/homedevanon/home-equestria/releases/tag/0.0.4-maredev). Nothing else. |
| Edit the game from source | `Source code` (or clone the repo) **plus** all three `source-data` zips from the [0.0.7-maredev release](https://github.com/homedevanon/home-equestria/releases/tag/0.0.7-maredev), extracted into the repo root next to `project.godot` (they hold the ground, foliage and other generated data git leaves out) |
